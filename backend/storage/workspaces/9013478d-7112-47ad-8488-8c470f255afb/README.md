# Solix Sample Project

This is a sample project running inside the **Solix Coding Workspace**.

### Features
- **Run code**: Click the `Run` button in the top bar or press `Ctrl+Enter`.
- **Test code**: Click the `Test` button to execute unit tests.
- **Solix AI Panel**: Ask Solix to explain, debug, fix, or refactor code.
- **Live Diff Review**: Solix generates structured patches that you can review side-by-side before applying.
